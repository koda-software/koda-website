Every code Opero and `opero-ext` report for extensions, grouped by where you meet it. Each row says what the code means and links to the section that explains the cause and the fix. Every problem in every file is reported in one run.

## When a package is refused

`opero-ext validate` finds these, and Opero again when the package is uploaded. Each names the file, the line and the place inside it, for example `actions/greet/rule.yaml:9 #/steps/0/config/url`.

## When the tests run at upload

Only Opero runs the tests, at upload and with `opero-ext test`. Each points at the case, for example `actions/greet/tests.yaml#/1`, and for an exchange or an effect at the place inside it.

| Code | Meaning |
| --- | --- |
| [`test.unexpected_request`](/docs/en/extensions/reference/tests#problems) | The action made a request the case did not script. |
| [`test.request_mismatch`](/docs/en/extensions/reference/tests#problems) | The method, URL, a named header or the body differs from the case. |
| [`test.unused_exchange`](/docs/en/extensions/reference/tests#problems) | The case scripted a request the action never made. |
| [`test.unexpected_effect`](/docs/en/extensions/reference/tests#problems) | The action ran a data step the case did not script next. |
| [`test.effect_mismatch`](/docs/en/extensions/reference/tests#problems) | A key an effect names differs from what the step was given, or the effect's `response` does not have the shape the step returns. |
| [`test.unused_effect`](/docs/en/extensions/reference/tests#problems) | The case scripted a data step the action never ran. |
| [`test.unexpected_event`](/docs/en/extensions/reference/tests#problems) | The action raised an event after those the case lists. |
| [`test.event_mismatch`](/docs/en/extensions/reference/tests#problems) | A raised event differs from the one the case lists at that position: its trigger, its key or its data. |
| [`test.missing_event`](/docs/en/extensions/reference/tests#problems) | The case lists an event the action did not raise. |
| [`test.outcome_mismatch`](/docs/en/extensions/reference/tests#problems) | The action ended differently than the case says. |
| [`test.output_mismatch`](/docs/en/extensions/reference/tests#problems) | The output differs from `returns`. |
| [`test.output_schema`](/docs/en/extensions/reference/tests#problems) | The output does not match the output fields. |
| [`test.failed`](/docs/en/extensions/reference/tests#problems) | The case could not finish, for example it ran out of time. |
| [`test.render_mismatch`](/docs/en/extensions/reference/blocks#problems) | A block render case: the HTML lacks a `contains` text, or has a `notContains` one. |
| [`test.render_failed`](/docs/en/extensions/reference/blocks#problems) | A block render case: the template did not render, for example because it uses a filter outside Opero's built-in ones. |

## In the install review

The [install review](/docs/en/extensions/install#the-install-review) of an install or an upgrade shows these. The API and `opero-ext plan` return them as the plan's issues. A code marked *Warning* does not block.

### On any install

| Code | Meaning |
| --- | --- |
| [`requires.release`](/docs/en/extensions/reference/manifest#problems) | This Opero is older than the package needs. |
| [`requires.release_unknown`](/docs/en/extensions/reference/manifest#problems) | This installation does not know its release, so `requires.opero` was not checked. *Warning.* |
| [`requires.module`](/docs/en/extensions/reference/manifest#problems) | A required module is not available here. |
| [`key.overlaps_installed`](/docs/en/extensions/reference/manifest#problems) | An installed extension's key overlaps this one, as `order` and `order-sync` do. Only one of them can be installed. |
| [`version.not_newer`](/docs/en/extensions/reference/manifest#problems) | An upgrade to the same or an older version. |
| [`permission.missing`](/docs/en/extensions/install#the-install-review) | The person installing lacks a permission the content needs. |
| [`permission.owner_required`](/docs/en/extensions/reference/data-permissions#problems) | The package declares data scopes and the person installing is not an organization owner. |
| [`rule.save_validation`](/docs/en/extensions/install#the-install-review) | An action's rule would not save. The message says why. |
| [`filter.save_validation`](/docs/en/extensions/reference/filters#problems) | A filter script would not save: it does not validate or its name is taken. |
| [`filter.not_sync`](/docs/en/extensions/reference/filters#problems) | A filter waits on something. Filters must answer at once. |
| [`object.save_validation`](/docs/en/extensions/reference/objects#problems) | An object or field would not save, for example an unknown field type or wrong options. |
| [`dictionary.save_validation`](/docs/en/extensions/reference/dictionaries#problems) | A dictionary would not save, for example because an entry that custom fields name would be removed. |

| [`EXTENSION_ACTION_INPUT_INVALID`](/docs/en/extensions/reference/actions#when-a-step-fails) | The step's input did not match the action's input fields. |
| [`EXTENSION_ACTION_OUTPUT_INVALID`](/docs/en/extensions/reference/actions#when-a-step-fails) | The action's result did not match its output fields. |

| [`service_connection_not_configured`](/docs/en/extensions/reference/data-steps#send-an-email) | A `SEND_EMAIL` step ran on an installation without an email service. |

| [`EXTENSION_EVENT_NOT_ALLOWED`](/docs/en/extensions/reference/raising-events#limits-and-failures) | An `EMIT_EVENT` step ran outside a schedule or connection-hook run, or for an undeclared trigger. |
| [`EXTENSION_ACTION_CREDENTIAL_REVOKED`](/docs/en/extensions/reference/member-connections#a-refused-token) | In a run for a member, the service answered `401` to the member's token. The member is asked to connect again. |
| [`EXTENSION_MANAGED_RULE_RUN`](/docs/en/extensions/reference/actions#problems) | Someone tried to run, test or replay an extension's rule directly. It runs only through its step. |
