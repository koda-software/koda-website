## What the field is for

A plain text field is enough for a name or a short remark. When you need to describe the outcome of a meeting, a matter description, or a procedure, you need text with paragraph breaks, bullet points, and highlights. The **rich text field** is for this: an editor embedded in the record form.

## Available actions

| Element | What for |
| --- | --- |
| Headings of six levels | dividing long text into parts |
| Bulleted and numbered lists | enumerations and the order of steps |
| A task list with checkboxes | a simple checklist inside the description |
| A table | a summary of values, including merged cells |
| A quote and a divider line | highlighting a fragment, dividing the content |
| A code block | a fragment of a configuration or a technical message |
| An image with a caption | a screenshot or a photo within the description |
| A person mention | tagging a coworker in the content |

For formatting the text itself you have bold, italic, underline, strikethrough, inline code, superscript and subscript, text color and background highlight in seven colors, and a link to an external address.

## Images

An image inserted into the content is **saved in the system together with the record**, not linked from the internet. Thanks to this it will not disappear when someone deletes it elsewhere. You can give an image a caption, set its width and alignment, including text wrapping.

## Mentions

A mention tags a person or a role directly in the content. It is used the same way as in comments: the tagged person gets a signal that they are needed on the matter.

Mentions are not available in every field. In content meant for publication, for example a product description or an article, the administrator usually disables them, because an employee's name must not go outside together with the content.

> **Example.** In a handover report you describe reservations in points, paste a photo of the fault with a caption, and tag the site manager with a mention. All the information stays at the record instead of circulating in e-mails.

## What to watch for

- **Do not paste whole documents.** If the content is a contract or a report in a ready file, attach the file as an attachment, and leave a summary in the description.
- **Do not build the page layout with tables.** A table is meant to contain data, not to arrange text in columns.
- **Pasting from Word can be capricious.** Some formatting has no equivalent in the editor and will be rejected. It is safer to paste the text without formatting and format it in place.
