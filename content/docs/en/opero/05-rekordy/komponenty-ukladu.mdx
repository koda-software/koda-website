## Form content beyond fields

Besides fields, a record form may contain elements that do not store information but show something or start something. It is worth recognizing them, because they behave differently from fields.

| Element | What it does |
| --- | --- |
| Divider line | organizes a long section, does nothing beyond that |
| Information block | shows content prepared by the administrator: an instruction, a warning, a summary |
| Button | starts an action, for example generates a document or opens a related screen |
| List | shows a summary of records related to the one you are on |
| Summary | shows a chart or a table built on the record's data |

## Buttons

A button on the form does exactly what its name describes. If the name is not obvious, ask the administrator instead of testing by trial: some actions change data or send something outside.

A button is sometimes visible only in certain situations, for example after the record is saved or at a specific stage of the matter. Its disappearance after a stage change is intended.

## Information blocks

An information block is a place where the administrator leaves content to be read, not filled in: a procedure, an explanation of what to watch for, a warning in an unusual situation. Sometimes its content changes depending on the record's contents.

> **Example.** On a leave request form an information block shows the number of days left to use, and when the limit is exceeded it changes into a warning. It is not a field, so it cannot be filled in.

## Lists and summaries

A list shows records related to the one you are on, and a summary presents data in the form of a chart or a table. Both are **for viewing only**: changes are made on the individual records' forms, which you can usually reach from the list.

If in a summary you see data you did not expect, check whether you are looking at the whole organization instead of your own department. The scope is set by the administrator when building the screen.
