Opero is a workspace for managing business operations, teams, contractors, documents, workflows, dictionaries, and service catalog data in one place.

These docs are for teams that want to connect Opero with their own systems. The Opero API lets applications work with selected Opero resources through token-authenticated HTTP requests.

## What you can integrate

The first API surface focuses on integration-friendly operational data:

- contractors, suppliers, and customers
- dictionaries and reference data
- service catalog items
- API token authentication checks
- health and availability checks

## Start here

Read the docs in this order:

- [Opero](/docs/en/opero) explains what Opero is and how its main product areas fit together.
- [Getting started](/docs/en/getting-started) explains the API base URL and first request.
- [Authentication](/docs/en/api/authentication) explains how to send an Opero API token.
- [Opero API](/docs/en/api) lists endpoint documentation and the interactive playground.

Documentation is available in English and Polish.
