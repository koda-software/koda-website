Opero to przestrzeń robocza do zarządzania operacjami biznesowymi, zespołem, kontrahentami, dokumentami, procesami, słownikami i katalogiem usług w jednym miejscu.

Ta dokumentacja jest przeznaczona dla zespołów, które chcą połączyć Opero z własnymi systemami. Opero API pozwala aplikacjom pracować z wybranymi zasobami Opero przez uwierzytelniane tokenem zapytania HTTP.

## Co możesz integrować

Pierwszy zakres API obejmuje dane operacyjne przydatne w integracjach:

- kontrahentów, dostawców i klientów
- słowniki oraz dane referencyjne
- pozycje katalogu usług
- sprawdzanie uwierzytelniania tokenem API
- sprawdzanie zdrowia i dostępności API
