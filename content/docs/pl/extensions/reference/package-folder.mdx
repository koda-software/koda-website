| Ścieżka | Zawiera |
| --- | --- |
| `extension.yaml` | Tożsamość, wymagania i uprawnienia oraz listy wszystkiego innego. Wymagany. Zobacz [extension.yaml](/docs/pl/extensions/reference/manifest). |
| `actions/<folder>/` | `action.yaml`, plik wskazany w `run` (plik reguły, skrypt albo plik reguły i skrypty, których używają jego kroki), plik lub folder z testami oraz ewentualne pliki schematów. Zobacz [Akcje](/docs/pl/extensions/reference/actions). |
| `filters/<folder>/` | `filter.yaml` i jego skrypt. Zobacz [Filtry](/docs/pl/extensions/reference/filters). |
| `objects/<folder>/` | `object.yaml`: jeden obiekt paczki. Zobacz [Obiekty](/docs/pl/extensions/reference/objects). |
| `dictionaries/<folder>/` | `dictionary.yaml`: jeden słownik. Zobacz [Słowniki](/docs/pl/extensions/reference/dictionaries). |
| `queries/<folder>/` | `query.yaml` i plik `.sql`, który wskazuje. Zobacz [Zapytania](/docs/pl/extensions/reference/queries). |
| `triggers/<folder>/` | `trigger.yaml`: jeden wyzwalacz reguł paczki i plik schematu jego danych, jeśli go używa. Zobacz [Wyzwalacze](/docs/pl/extensions/reference/triggers). |
| `schedules/<folder>/` | `schedule.yaml`: jeden harmonogram. Zobacz [Harmonogramy](/docs/pl/extensions/reference/schedules). |
| `blocks/<folder>/` | `block.yaml`, plik HTML, wskazane przez niego pliki CSS i skryptu oraz testy renderowania. Zobacz [Bloki](/docs/pl/extensions/reference/blocks). |
| `links/<folder>/` | `link.yaml`: jeden link rekordu. Zobacz [Linki rekordów](/docs/pl/extensions/reference/record-links). |
| `forms/<folder>/` | `form.yaml` i plik jego układu: jeden formularz na obiekcie paczki. Zobacz [Formularze, listy i strony](/docs/pl/extensions/reference/screens#formyaml). |
| `lists/<folder>/` | `list.yaml`: jedna lista własna. Zobacz [Formularze, listy i strony](/docs/pl/extensions/reference/screens#listyaml). |
| `pages/<folder>/` | `page.yaml` i plik jej układu: jedna strona obszaru roboczego. Zobacz [Formularze, listy i strony](/docs/pl/extensions/reference/screens#pageyaml). |
| `settings.yaml` | Ustawienia rozszerzenia, gdy `extension.yaml` zawiera `settings: settings.yaml`. Zobacz [Ustawienia](/docs/pl/extensions/reference/settings). |
| `connection/` | `connection.yaml`, gdy `extension.yaml` zawiera `connection: connection`, oraz `member.yaml`, gdy `connection.yaml` zawiera `member: member.yaml`. Zobacz [Połączenie i sekrety](/docs/pl/extensions/reference/connection-and-secrets) i [Połączenia członków](/docs/pl/extensions/reference/member-connections). |
| `<module>/module.yaml` | Grupa funkcji we własnym folderze, dla dużej paczki. Zobacz [Moduły](#modules). |
| `locales/<lang>.yaml` | Jedno tłumaczenie na każdy język z listy `locales`. Zobacz [Tłumaczenia](/docs/pl/extensions/reference/translations). |
| Wszystko inne | README, changelog, licencja, pliki CI, ustawienia edytora: pomijane i niepakowane. |

<Callout type="warn">
Plik deskryptora (`action.yaml`, `filter.yaml`, `object.yaml` itd.), którego nie wymienia żadna lista, zostaje odrzucony z kodem `layout.unlisted_feature`. Dodaj jego folder do listy albo go usuń. To samo dotyczy pliku `settings.yaml`, którego nie wskazuje `extension.yaml`, i pliku `connection/member.yaml`, którego nie wskazuje `connection.yaml`.
</Callout>

## Nazwy

- Każdy plik używany przez paczkę ma ścieżkę małymi literami: litery, cyfry, `.`, `_` i `-`.
- Nazwy deskryptorów są stałe. Nazwy folderów wybierasz sam i nigdy nie stają się identyfikatorami, więc możesz zmienić nazwę folderu bez psucia czegokolwiek, co korzysta z danej funkcji.

## Zasady YAML

YAML jest czytany ściśle:

- jeden dokument na plik, UTF-8;
- bez kotwic, aliasów, tagów, kluczy scalania i powtórzonych kluczy.

JSON jest poprawnym YAML-em, więc regułę wyeksportowaną z edytora reguł możesz wkleić bez zmian.

## Moduły [#modules]

Duża paczka może grupować funkcje w folderach modułów. Każdy folder modułu zawiera `module.yaml`:

```yaml title="billing/module.yaml"
module: billing
name: Billing
description: Invoice and payment steps.
actions:
  - actions/create-invoice
  - actions/send-invoice
filters:
  - filters/invoice-number
```

| Klucz | Znaczenie |
| --- | --- |
| `module` | Klucz modułu. |
| `name` | Jego nazwa. |
| `description` | Opcjonalny. |
| `actions`, `filters`, `objects`, `dictionaries`, `queries`, `triggers`, `schedules`, `blocks`, `links`, `forms`, `lists`, `pages` | Jego własne listy, względem folderu modułu. Obiekty ze wszystkich folderów modułów i tak trafiają do jednego modułu `x-<key>` rozszerzenia. |

`extension.yaml` wskazuje folder modułu w `include`. Moduły mają tylko jeden poziom zagnieżdżenia.

```yaml title="extension.yaml"
include:
  - billing
```
