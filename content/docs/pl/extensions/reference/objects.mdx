Obiekt to tabela rekordów, którą rozszerzenie przynosi ze sobą, na przykład zamówienia albo przesyłki. Przy instalacji Opero tworzy prawdziwą tabelę dla każdego obiektu, w jednym module nazwanym od rozszerzenia, `x-<key>`; reguły paczki docierają do rekordów [krokami danych](/docs/pl/extensions/reference/data-steps). Dwa obiekty buduje przewodnik [Paczka z własnymi danymi](/docs/pl/extensions/own-data).

```yaml title="objects/orders/object.yaml"
object: orders
name: Order
namePlural: Orders
icon: package
fields:
  - { key: number, name: Number, type: TEXT, isIndexed: true }
  - key: status
    name: Status
    type: SELECT
    options: { dictionary: status }
  - { key: ordered_on, name: Ordered on, type: DATE }
  - key: last_note
    name: Last note
    type: REFERENCE
    options: { toObject: order-notes }
```

Każdy obiekt ma własny folder w `objects/`, wymieniony w `objects` w `extension.yaml`, a paczka z obiektami wymienia `objects` w `requires.modules`.

## Odwołania wewnątrz paczki [#references-inside-the-package]

Pole wskazuje słownik albo inny obiekt tej samej paczki nazwą, nigdy identyfikatorem. Opero wpisuje w to miejsce identyfikatory z instalacji.

| Opcja | W polu typu | Wskazuje |
| --- | --- | --- |
| `dictionary: <name>` | `SELECT`, `MULTI_SELECT` | [Słownik](/docs/pl/extensions/reference/dictionaries) paczki. |
| `toObject: <object>` | `REFERENCE`, `SUBORDINATE_OBJECT_REFERENCE` | Obiekt paczki, według jego klucza `object`. Dwa obiekty mogą wskazywać na siebie nawzajem, a obiekt na samego siebie. |

Pole nie może zawierać `dictionaryId`, `toObjectId`, `toObjectClientId`, `toModuleKey` ani `toObjectKey`: paczka nie może wskazywać własnych słowników ani obiektów organizacji.

## Obiekt nie ma formularza [#no-form-comes-with-an-object]

Instalacja obiektu tworzy tylko jego tabelę i pola, bez formularza, listy, strony i pozycji menu, dlatego `createDefaultForm` jest odrzucane. Ekrany dostarcz jako [formularze, listy i strony](/docs/pl/extensions/reference/screens).

## Moduł [#the-module]

Wszystkie obiekty paczki należą do modułu `x-<key>`. Organizacja nie może utworzyć modułu, którego klucz zaczyna się od `x-`, więc ten moduł może należeć tylko do tego rozszerzenia. Kształtem obiektu zarządza rozszerzenie, a jego rekordy pozostają własnością organizacji; zobacz [Zasoby zarządzane](/docs/pl/extensions/after-install#managed-assets).

## Aktualizacje [#upgrades]

| Zmiana w nowej wersji | Co się dzieje | Kod |
| --- | --- | --- |
| Dodano obiekt albo pole | Zostaje utworzone. | |
| Usunięto pole albo obiekt | Jego wartości albo rekordy są usuwane, gdy administrator potwierdzi utratę. | |
| Pole zmieniło się tak, że jego zapisane wartości trzeba wyczyścić | To samo. | |
| Instalacja przejmuje obiekt zachowany przy wcześniejszym odinstalowaniu | Obiekt znów należy do rozszerzenia. Ostrzeżenie. | `object.adopts_existing` |

Odinstalowanie domyślnie zachowuje obiekty i ich rekordy jako własność organizacji. Co widzi administrator, opisują sekcje [Gdy aktualizacja usuwa dane](/docs/pl/extensions/upgrade-and-uninstall#when-an-upgrade-deletes-data) i [Zachowanie lub usunięcie danych](/docs/pl/extensions/upgrade-and-uninstall#keep-or-delete-the-data).

## Problemy [#problems]

| Kod | Przyczyna | Rozwiązanie |
| --- | --- | --- |
| `object.invalid` | Nieznany klucz, klucz albo pole o złej strukturze, `createDefaultForm`, opcja wskazująca identyfikator albo inny moduł, `dictionary` w polu, które nie jest wyborem, `toObject` w polu, które nie jest odwołaniem, albo więcej niż 50 obiektów. | Popraw klucz wskazany w komunikacie. |
| `object.unknown_reference` | `dictionary` albo `toObject` nie wskazuje niczego w paczce. | Popraw nazwę albo dodaj słownik lub obiekt. |
| `name.duplicate` | Dwa obiekty o tym samym kluczu `object`. | Zmień nazwę jednego z nich. |
| `requires.module_undeclared` | Paczka ma obiekty, ale w `requires.modules` brakuje `objects`. | Dodaj `objects`. |
| `object.save_validation` | W przeglądzie instalacji: obiektu albo pola nie da się zapisać, na przykład przez nieznany typ pola albo złe opcje. Blokuje instalację. | Popraw pole zgodnie z komunikatem. |
