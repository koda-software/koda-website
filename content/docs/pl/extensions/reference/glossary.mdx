## Pojęcia [#words]

| Pojęcie | Znaczenie |
| --- | --- |
| Akcja | Folder z `action.yaml`, logiką (plikiem reguły albo skryptem) i testami. Zobacz [Akcje](/docs/pl/extensions/reference/actions). |
| Akcja bloku | Akcja, którą uruchamia przycisk w jednym z bloków paczki, jako członek, który go nacisnął. |
| Akcja członka | Akcja, która używa własnego połączenia członka, `{{ userConnection.<field> }}`. Działa tylko dla jednego członka. |
| Blok | Fragment strony, który przynosi paczka: HTML z Liquid, CSS i opcjonalny skrypt. Zobacz [Bloki](/docs/pl/extensions/reference/blocks). |
| Część | Jedna funkcja paczki we własnym folderze: akcja, filtr, obiekt, wyzwalacz, blok, strona i tak dalej. |
| Deskryptor | Plik YAML opisujący jedną część, na przykład `action.yaml` albo `object.yaml`. Jego nazwa jest stała. |
| Efekt | Krok danych lub wiadomości zapisany w przypadku testowym, tak jak `http` zapisuje wywołanie. Zobacz [Testy](/docs/pl/extensions/reference/tests#data-and-messaging-steps). |
| Filtr | Filtr szablonów: mała funkcja, której może używać każdy szablon organizacji. Zobacz [Filtry szablonów](/docs/pl/extensions/reference/filters). |
| Harmonogram | Akcja, którą paczka uruchamia samodzielnie w stałym odstępie, dla instalacji, każdej firmy albo każdego połączonego członka. |
| Klucz | Identyfikator rozszerzenia, na przykład `hello-ext`. Od niego pochodzą nazwy wszystkiego, co rozszerzenie dodaje. |
| Krok | Akcja opublikowana w edytorze reguł, żeby reguły organizacji mogły jej używać. |
| Link rekordu | Akcja rekordu, która otwiera w przeglądarce członka stronę usługi dla tego rekordu. |
| Manifest | `extension.yaml`, plik na górze folderu, który wymienia całą zawartość paczki. Zobacz [extension.yaml](/docs/pl/extensions/reference/manifest). |
| Moduł | Folder części z własnym `module.yaml`, dla dużej paczki. Zobacz [Moduły](/docs/pl/extensions/reference/package-folder#modules). |
| Paczka | Jedna przesłana wersja rozszerzenia: plik zip z twoim folderem. Wersja nigdy się nie zmienia po przesłaniu. |
| Paczka prywatna | Paczka, którą organizacja przesłała dla siebie. |
| Paczka z katalogu | Paczka, którą administrator instalacji przesłał i udostępnił organizacjom. Drugi rodzaj to paczka prywatna. |
| Plik reguły | Logika akcji zapisana jako reguła: kroki i krawędzie, które zapisuje edytor reguł. Zobacz [Pliki reguł](/docs/pl/extensions/reference/rule-files). |
| Polecenie rekordu | Akcja oferowana wśród akcji rekordu, uruchamiana przez członka dla tego rekordu. |
| Połączenie | Zapisane dane uwierzytelniające usługi zewnętrznej, skonfigurowane przez administratora. Zobacz [Połączenie i sekrety](/docs/pl/extensions/reference/connection-and-secrets). |
| Połączenie członka | Własne konto członka w usłudze zewnętrznej, połączone przez niego samego przez OAuth. Zobacz [Połączenia członków](/docs/pl/extensions/reference/member-connections). |
| Przypadek testowy | Jeden wpis w testach akcji: wejście, wymiany HTTP i kroki danych wykonywane przez akcję, zgłaszane zdarzenia i to, jak się kończy. Działa przy przesłaniu, bez dostępu do sieci i do jakichkolwiek danych. Zobacz [Testy](/docs/pl/extensions/reference/tests). |
| Uprawnienie paczki | Uprawnienie firmowe deklarowane przez paczkę, którego członkowie potrzebują do jej akcji bloków, poleceń rekordów i linków. Zobacz [Uprawnienia paczki](/docs/pl/extensions/reference/package-permissions). |
| Ustawienia | Wartości, które nie są sekretne, wybierane przez administratora dla zainstalowanego rozszerzenia i odczytywane przez jego akcje. |
| Wizytówka | Ikona, długi opis, zrzuty ekranu i lista zmian, które administratorzy czytają o paczce. Zobacz [Wizytówka w katalogu](/docs/pl/extensions/reference/listing). |
| Wyzwalacz | Wyzwalacz reguł zadeklarowany przez paczkę. Paczka zgłasza jego zdarzenia, a reguły organizacji na nich się zaczynają. |
| Zakres danych | Jeden wpis w `permissions.data`: coś, co reguły paczki mogą robić z danymi, na przykład `records:write`. Zobacz [Uprawnienia do danych](/docs/pl/extensions/reference/data-permissions). |
| Zarządzane | Zainstalowane przez rozszerzenie i tylko do odczytu, dopóki rozszerzenie go nie zmieni. Zobacz [Zasoby zarządzane](/docs/pl/extensions/after-install#managed-assets). |
| Zdarzenie | Jedno wystąpienie wyzwalacza wraz z danymi, zgłoszone krokiem `EMIT_EVENT` paczki. |

## Nazwy po instalacji [#names-after-install]

Wszystko, co instaluje rozszerzenie, nosi nazwę pochodzącą od jego klucza, więc dwa rozszerzenia nigdy się nie zderzą. Tam, gdzie nazwa nie może zawierać myślnika, myślniki klucza zamieniają się w podkreślenia.

| Co | Nazwa | Dla klucza `polar-eu` |
| --- | --- | --- |
| Krok reguły | `x-<key>.<action>` | `x-polar-eu.sync` |
| Zainstalowana reguła akcji | `<nazwa paczki>: <etykieta akcji>` | `Polar: Sync` |
| Filtr szablonów | `x_<key z _>_<filter>` | `x_polar_eu_pace` |
| Połączenie | `x-<key>` | `x-polar-eu` |
| Moduł obiektów | `x-<key>` | `x-polar-eu` |
| Słownik | `x-<key>-<dictionary>` | `x-polar-eu-sports` |
| Zapisane zapytanie | `x_<key z _>_<query>` | `x_polar_eu_weekly_totals` |
| Wyzwalacz reguł | `x-<key>.<trigger>` | `x-polar-eu.daily_activity` |
| Blok | `x_<key z _>_<block>` | `x_polar_eu_week_card` |
| Akcja bloku, polecenie rekordu | `x-<key>.<action>` | `x-polar-eu.sync` |
| Link rekordu | `x-<key>.<link>` | `x-polar-eu.open_profile` |
| Uprawnienie paczki | `company.x-<key>.<name>` | `company.x-polar-eu.sync` |
| Lista własna | `x-<key>-<list>` | `x-polar-eu-weeks` |
| Adres (slug) strony | `x-<key>-<page>` | `x-polar-eu-overview` |

Część zachowuje tożsamość między wersjami, dopóki jej nazwa się nie zmienia, więc to, co organizacja na niej zbudowała, działa dalej po aktualizacji. Organizacja nie może tworzyć własnych modułów, słowników, list ani stron zaczynających się od `x-` ani zapytań, skryptów i bloków zaczynających się od `x_`.
