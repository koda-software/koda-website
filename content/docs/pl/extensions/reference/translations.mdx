description: "Tłumaczenie rozszerzenia Opero: angielski w deskryptorach, jeden plik locales na język, klucze do przetłumaczenia, limity i powrót do angielskiego przy brakach."
---

Angielski piszesz w deskryptorach. Każdy inny język to jeden plik, `locales/<lang>.yaml`, zagnieżdżony tak jak paczka. Tekst, który pominiesz, wyświetla się po angielsku.

<Steps>
<Step>
### Wymień język

```yaml title="extension.yaml"
locales: [pl, de]
```

Nie wymieniaj `en`: angielski jest w deskryptorach.
</Step>
<Step>
### Dodaj jeden plik na język

```yaml title="locales/pl.yaml"
extension:
  name: Hello
  description: Rozszerzenie startowe z powitaniem, wywołaniem httpbin.org i filtrem.
permissions:
  network:
    httpbin.org: { reason: Sprawdza token i wysyła powitania do testowej usługi httpbin.org. }
connection:
  methods:
    token:
      label: Token API
      fields: { token: { label: Token API } }
settings:
  groups:
    general:
      label: Ogólne
      description: Jak wysyłane są powitania.
  fields:
    language: { label: Język }
actions:
  greet:
    label: Pozdrów
    description: Wysyła powitanie dla imienia do httpbin.org i zwraca jego odpowiedź.
    input: { name: { label: Imię } }
filters:
  shout: { description: Zamienia tekst na wielkie litery i dodaje wykrzyknik. }
```
</Step>
<Step>
### Zwaliduj

`opero-ext validate .` zgłasza język bez pliku (`locale.missing_file`) i klucz, który nie wskazuje niczego w paczce (`locale.unknown_text`), więc literówka się nie ukryje.
</Step>
</Steps>

## Klucze do przetłumaczenia

| Klucz | Tłumaczy |
| --- | --- |
| `extension.name`, `extension.description` | Nazwę i opis paczki. |
| `permissions.network.<host>.reason` | Uzasadnienie hosta. Także `permissions.data.<scope>.reason`. |
| `connection.methods.<method>.label` | Etykietę metody; jej pola w `fields.<field>.label` i `help`. |
| `settings.groups.<group>.label`, `description` | Tytuł i opis grupy ustawień. |
| `settings.fields.<field>.label` | Etykietę ustawienia oraz `help`, według klucza pola, bez jego grupy; pola zagnieżdżone w `fields`, elementy listy w `items`. |
| `actions.<action>.label`, `description` | Akcję i jej krok. |
| `actions.<action>.input.<field>.label` | Etykietę pola i `help`; także `output`, zagnieżdżone pola w `fields`, elementy listy w `items`. |
| `filters.<filter>.description` | Opis filtra. |
| `dictionaries.<dictionary>.entries.<key>.label` | Etykietę pozycji słownika. |
| `triggers.<trigger>.label`, `description` | Nazwę i opis wyzwalacza; jego pola danych w `data.<field>` i filtry w `config.<field>`, każde z `label` i `help`. |
| `schedules.<schedule>.label`, `description` | Nazwę i opis harmonogramu. |
| `member.label`, `member.description` | Nazwę i opis połączenia członka. |
| `member.data."<i>"` | Jeden z tekstów `data` połączenia członka, według pozycji od 0, w cudzysłowie. |
| `member.failures.<name>` | Komunikat błędu łączenia. |
| `member.config.<field>.label` | Pole formularza członka i jego `help`. |
| `actions.<action>.confirm.title`, `message` | Potwierdzenie polecenia rekordu. |
| `blocks.<block>.label`, `description` | Nazwę i opis bloku. Jego HTML nie jest tłumaczony. |
| `links.<link>.label`, `description` | Etykietę i opis linku rekordu; jego pola w `fields.<field>.label`. |
| `permissions.links.<host>.reason`, `permissions.pageScript.reason` | Uzasadnienie hosta linku i skryptów stron. |
| `permissions.company.<name>.label`, `description`, `reason` | Teksty uprawnienia paczki. |
| `pages.<page>.title`, `description` | Tytuł i opis strony. |
| `forms.<object>.<form>.config.title`, `successMessage` | Tytuł i komunikat po zapisie formularza. Są sprawdzane, ale formularz jest instalowany z tekstami angielskimi. |

## Zasady

- Każde tłumaczenie to tekst do 2000 znaków.
- Paczka może mieć do 40 języków.
- Teksty pliku schematu są tylko po angielsku.
- Nazwy obiektów i ich pól, słowników i zapytań są tylko po angielsku, podobnie jak nazwy formularzy, nazwy i opisy list, etykiety kolumn i etykiety akcji list: Opero nie przechowuje dla nich tłumaczeń, więc tłumaczenie, które którąś z nich wskazuje, jest odrzucane z kodem `locale.unknown_text`. Ze słownika tłumaczy się tylko etykiety pozycji.
