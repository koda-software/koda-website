`extension.yaml` to manifest: tożsamość paczki, jej wymagania, to, do czego ma dostęp, oraz lista wszystkich funkcji, które instaluje.

```yaml title="extension.yaml"
manifestVersion: 2
extension: hello-ext
version: 0.1.0
name: Hello
description: A starter extension with a greeting, a call to httpbin.org and a filter.
publisher: Your company
requires:
  opero: ">=2026.1.0"
  modules: [rules]
permissions:
  network:
    - host: httpbin.org
      reason: Checks the token and sends greetings to the httpbin.org test service.

connection: connection
settings: settings.yaml

actions:
  - actions/hello
  - actions/verify
  - actions/greet
filters:
  - filters/shout

locales: [pl]
```

## Uprawnienia sieciowe

Każdy host, z którym łączy się paczka, jest wymieniony z uzasadnieniem. Administrator widzi każdy host i jego uzasadnienie w planie instalacji, zanim cokolwiek zostanie zainstalowane.

```yaml title="extension.yaml"
permissions:
  network:
    - host: api.example.com
      reason: Creates shipments and reads their tracking numbers.
    - host: auth.example.com
      reason: Exchanges the API key for a short-lived access token.
```

- Wywołanie hosta spoza listy jest odrzucane, zarówno przy sprawdzaniu paczki, jak i w trakcie działania.
- Host bez uzasadnienia jest odrzucany z kodem `permissions.reason_required`.
- Paczka z połączeniem wymienia co najmniej jeden host.
- Gdy aktualizacja prosi o nowe hosty, plan oznacza je jako nowe w tej wersji.

## Zarezerwowane listy

Nazwy list `objects`, `dictionaries`, `queries`, `blocks`, `components`, `triggers` i `schedules` są zarezerwowane dla przyszłych wersji i dziś odrzucane z kodem `manifest.unsupported_section`.
