description: Dodaj ekrany członków, czyli formularze na obiektach paczki, listy własne i strony obszaru roboczego, przez form.yaml, list.yaml i page.yaml.
---

Paczka może przynieść ekrany, na których pracują członkowie: **formularze** na własnych obiektach, **listy własne** (Custom Lists), które wyświetlają rekordy, i **strony obszaru roboczego**, które łączą listy, formularze, bloki i liczniki. Są instalowane jako formularze dynamiczne, listy własne i strony własne (Custom Pages) organizacji, zarządzane przez rozszerzenie. Wszystkie trzy buduje przewodnik [Formularze, listy i strony](/docs/pl/extensions/workspace-screens).

```yaml title="extension.yaml"
manifestVersion: 2
extension: shop
version: 1.0.0
name: Shop
description: Keeps orders with their lines, and the screens to work with them.
publisher: Kodasoft
requires:
  opero: ">=2026.1.0"
  modules: [objects, queries]
permissions:
  links:
    - host: shop.example.test
      reason: Opens an order in the shop.
objects:
  - objects/orders
  - objects/order-lines
queries:
  - queries/open-count
blocks:
  - blocks/order-summary
forms:
  - forms/order
  - forms/line
lists:
  - lists/open-orders
  - lists/order-lines
  - lists/suppliers
pages:
  - pages/orders
locales: [pl]
```

Wpisz foldery na listach `forms`, `lists` i `pages` w `extension.yaml` albo w `module.yaml` dołączonego modułu. `opero-ext add form <name> --object <object>`, `add list <name> [--object <object>]` i `add page <name>` zapisują folder startowy i dopisują go do listy; zobacz [Narzędzie wiersza poleceń](/docs/pl/extensions/reference/cli#options).

## form.yaml [#formyaml]

Formularz to formularz dynamiczny na jednym z własnych [obiektów](/docs/pl/extensions/reference/objects) paczki: ekran, który otwiera, edytuje albo tworzy jego rekordy. Paczka ma najwyżej 100 formularzy.

```yaml title="forms/order/form.yaml"
form: order                      # referenced as orders.order
object: orders
name: Order
types: [view, edit, create]
default: [view, edit, create]    # claims the object's slots when they are empty
config:
  title: New order
  successMessage: Saved
layout: layout.yaml
```

Układ to dokument układu widoku (View Layout), taki, jaki zapisuje edytor formularzy. Węzły pól podają klucze pól obiektu; bloki, listy, formularze i zapytania paczki wskazuje się [odwołaniami](#references):

```yaml title="forms/order/layout.yaml"
schemaVersion: 2
regions:
  main:
    - id: details
      kind: card
      children:
        - { id: f_title, kind: field, field: { source: dynamic, key: title } }
        - { id: f_status, kind: field, field: { source: dynamic, key: status } }
    - id: summary
      kind: component
      component: custom_block
      config:
        customBlockId: { $ref: "block:order_summary" }
        inputs: { title: "Order {{ record.title }}" }
    - id: lines
      kind: component
      component: layout.customList
      config:
        customListId: { $ref: "list:order-lines" }
        params: { order: "{{ record.id }}" }
```

### Formularze domyślne [#default-forms]

Każdy obiekt ma domyślny formularz do oglądania, edycji i tworzenia rekordów. Formularz z `default` zajmuje każde wskazane miejsce, które jest puste albo zajęte przez formularz tego rozszerzenia. Miejsce, w którym organizacja ustawiła własny formularz, zostaje bez zmian, a przegląd instalacji to mówi (`form.default_taken`, nie blokuje). Aktualizacja i ponowna instalacja robią to samo: nigdy nie przejmują domyślnego formularza wybranego przez organizację.

## list.yaml [#listyaml]

Lista to lista własna na jednym z obiektów paczki albo na wbudowanym źródle list. Członkowie widzą ją tam, gdzie osadza ją strona albo formularz. Paczka ma najwyżej 50 list.

```yaml title="lists/open-orders/list.yaml"
list: open-orders                # installed as x-shop-open-orders
name: Open orders
description: Orders that are not closed yet.
source: { object: orders }
config:
  columns: [{ field: title }, { field: status }]
  baseFilter:
    op: AND
    items: [{ field: status, operator: neq, value: closed }]
  modes: [table]
  views: [{ id: default, name: Default, default: true, config: { schemaVersion: 2 } }]
  builtInActions: [create, open]
  create: { formId: { $ref: "form:orders.order" } }
actions:
  - key: open_in_shop
    type: OPEN_LINK
    label: Open in shop
    config: { url: "https://shop.example.test/orders/{{ row.external_id }}" }
```

list: suppliers
name: Suppliers

Czytnik sprawdza budowę i odwołania. To, czy konfiguracja pasuje do źródła (kolumny, filtry i formularz tworzenia), Opero sprawdza tak, jak zrobiłby to zapis samej listy: w przeglądzie instalacji (`list.save_validation`), a dla listy na obiekcie, który tworzy ta sama instalacja, przy instalowaniu listy.

### Akcje [#actions]

Lista z paczki ma tylko akcje `OPEN_LINK`, które otwierają adres dla wiersza. Akcja reguły albo skryptu jest odrzucana z kodem `list.action_unsupported`: ich identyfikatory nie mogą podróżować z paczką.

| Klucz | Znaczenie |
| --- | --- |
| `key` | Mała litera, potem małe litery, cyfry i `_`, do 80 znaków. Unikalny w liście. |
| `label` | Do 160 znaków. |
| `type` | `OPEN_LINK`. |
| `isActive` | Opcjonalne. |
| `config.url` | Ścieżka albo adres https na hoście z `permissions.links`, z Liquid nad `row`. Zobacz [Adresy URL](#urls). |
| `config.openIn` | `same_tab` albo `new_tab`. Gdy pominięte, `new_tab`. |
| `config.isDefault` | Opcjonalne. Pokazuje akcję jako skrót wiersza obok menu jego akcji. |

## Odwołania [#references]

Ekran nigdy nie wskazuje niczego identyfikatorem, bo identyfikatory są w każdej organizacji inne. Własne bloki, listy, formularze i zapytania paczki wskazuje odwołaniem, które Opero zastępuje identyfikatorem po instalacji:

```yaml
customListId: { $ref: "list:open-orders" }
```

| Rodzaj | Wskazuje | Przykład |
| --- | --- | --- |
| `block` | [Blok](/docs/pl/extensions/reference/blocks) po nazwie z `block`. | `{ $ref: "block:order_summary" }` |
| `list` | Listę po nazwie z `list`. | `{ $ref: "list:open-orders" }` |
| `form` | Formularz jako `<object>.<form>`. | `{ $ref: "form:orders.order" }` |
| `query` | [Zapytanie](/docs/pl/extensions/reference/queries) po nazwie z `query`. | `{ $ref: "query:open_count" }` |

Odwołanie może stać tylko tam, gdzie Opero przechowuje identyfikator jego rodzaju:

| Gdzie | Rodzaj |
| --- | --- |
| `config.customBlockId` komponentu `custom_block` | `block` |
| `config.customListId` komponentu `layout.customList` | `list` |
| `config.formId` komponentu `page.form` | `form` |
| `config.savedQueryId` komponentu `counter` albo `page.counter` | `query` |
| `owned.rowForms.<operation>` węzła `field` albo `relationTable` | `form` |
| `config.create.formId` listy | `form` |

Odrzucane są: odwołanie w każdym innym miejscu, odwołanie, które nie ma dokładnie postaci `{ $ref: "<kind>:<name>" }`, nazwa, której paczka nie ma, i każdy inny klucz z identyfikatorem (reguły, raportu, procesu, kalendarza, listy SQL albo pola własnego: każdy klucz kończący się na `Id` lub `Ids`); zobacz [Problemy](#problems). Pomiń taki klucz albo zostaw go pustym.

Klucze pól i relacji wpisuje się bez zmian: są takie same w każdej organizacji, która instaluje paczkę.

## Adresy URL [#urls]

`url` w układzie, `config.url` akcji listy i `config.redirectUrl` formularza muszą być albo ścieżką Opero zaczynającą się od `/`, albo adresem https, którego host jest wpisany wprost i wymieniony w [`permissions.links`](/docs/pl/extensions/reference/manifest#link-hosts-page-scripts-and-company-permissions). Liquid może uzupełnić ścieżkę, nigdy host. Wszystko inne jest odrzucane z kodem `layout.host_not_declared`. Host, który otwierają ekrany, liczy się jako używany, więc nie potrzebuje linku rekordu.

## Tłumaczenia [#translations]

`title` i `description` strony trafiają do `pages.<page>`, a `config.title` i `successMessage` formularza do `forms.<object>.<form>.config`; formularz jest instalowany z angielskimi tekstami. Nazwy formularzy i list, etykiety kolumn i akcji są tylko po angielsku. Zobacz [Tłumaczenia](/docs/pl/extensions/reference/translations#translatable-keys).

## Zastrzeżone nazwy [#reserved-names]

Organizacja nie może utworzyć listy własnej z kluczem zaczynającym się od `x-` ani utworzyć strony ze slugiem zaczynającym się od `x-` lub nadać jej takiego sluga, więc te klucze mogą należeć tylko do rozszerzenia. Ekrany są tylko do odczytu i zmieniają się tylko przy aktualizacji; to, kto może używać każdego formularza, formularze domyślne obiektu, udostępnienie i odbiorcy strony oraz menu pozostają w gestii organizacji. Zobacz [Zasoby zarządzane](/docs/pl/extensions/after-install#managed-assets), a to, kto widzi ekrany po instalacji, w sekcji [Po instalacji](/docs/pl/extensions/workspace-screens#after-install).

## Aktualizacje [#upgrades]

| Zmiana w nowej wersji | Co się dzieje | Kod |
| --- | --- | --- |
| Zmienił się układ formularza albo strony | Jest publikowany jako nowa wersja. | |
| Zmieniła się lista | Jest zapisywana w miejsce poprzedniej. | |
| Formularz zajmuje domyślne miejsce, które organizacja wypełniła | Miejsce zachowuje formularz organizacji. Ostrzeżenie. | `form.default_taken` |
| Usunięto formularz, który wskazują układy, listy albo bloki organizacji | Formularz jest usuwany; jego miejsca domyślne przechodzą na inny formularz rozszerzenia tego samego typu albo zostają puste. Ostrzeżenie. | `form.in_use` |
| Usunięto ostatni formularz danego typu dla obiektu | Członkowie nie mogą otwierać ani tworzyć jego rekordów, dopóki administrator nie zbuduje formularza. Ostrzeżenie. | `object.formless` |
| Usunięto listę, którą osadzają układy organizacji | Jest archiwizowana, a osadzenia pokazują, że rozszerzenie ją usunęło. Ostrzeżenie. | `list.in_use` |
| Usunięto stronę, którą otwierają menu organizacji | Jest archiwizowana, a pozycje menu są ukrywane. Ostrzeżenie. | `page.in_use` |

Odinstalowanie usuwa formularze oraz archiwizuje listy i strony; ponowna instalacja przywraca listy i strony pod tymi samymi identyfikatorami. Co widzi administrator, opisuje strona [Aktualizacja i odinstalowanie](/docs/pl/extensions/upgrade-and-uninstall#what-a-new-version-can-change).

## Problemy [#problems]

| Kod | Przyczyna | Rozwiązanie |
| --- | --- | --- |
| `form.invalid` | Nieznany klucz, klucz o złej strukturze, brak `types`, miejsce w `default` spoza jego typów, układ, który nie jest plikiem `.yaml` z folderu z `schemaVersion: 2` i `regions`, albo więcej niż 100 formularzy. | Popraw klucz wskazany w komunikacie. |
| `form.unknown_object` | `object` nie wskazuje żadnego obiektu paczki. | Popraw klucz albo dodaj obiekt. |
| `list.invalid` | Nieznany klucz, klucz o złej strukturze, źródło `builtIn: dynamicObject` albo więcej niż 50 list. | Popraw klucz; dla obiektu napisz `source: { object: <key> }`. |
| `list.unknown_object` | `source.object` nie wskazuje żadnego obiektu paczki. | Popraw klucz albo dodaj obiekt. |
| `list.name_too_long` | Klucz po instalacji `x-<key>-<list>` ma ponad 64 znaki. | Skróć nazwę listy. |
| `list.action_unsupported` | Akcja listy inna niż `OPEN_LINK`. | Otwieraj link albo przenieś pracę do akcji bloku. |
| `page.invalid` | Nieznany klucz, klucz o złej strukturze, układ, który nie jest plikiem `.yaml` z folderu z `schemaVersion: 2` i `regions`, albo więcej niż 50 stron. | Popraw klucz wskazany w komunikacie. |
| `layout.ref_invalid` | Odwołanie, które nie ma dokładnie postaci `{ $ref: "<kind>:<name>" }`. | Zapisz je w tej postaci. |
| `layout.ref_position` | Odwołanie poza miejscami z tabeli albo niewłaściwego rodzaju dla swojego miejsca. | Przenieś je albo użyj rodzaju, który przyjmuje to miejsce. |
| `layout.ref_unknown` | Odwołanie wskazuje coś, czego paczka nie ma. | Popraw nazwę. |
| `layout.reference_unsupported` | Klucz z identyfikatorem, którego paczka nie może przenieść, albo identyfikator tam, gdzie powinno być odwołanie. | Pomiń klucz albo użyj odwołania. |
| `layout.host_not_declared` | Adres URL, który nie jest ani ścieżką Opero, ani adresem https na hoście z `permissions.links`. | Dodaj host z powodem albo użyj ścieżki. |
| `form.save_validation`, `layout.save_validation`, `list.save_validation` | W przeglądzie instalacji: formularza, układu albo listy nie da się zapisać tak, jak zapisuje je ich edytor. Blokuje instalację. | Popraw je zgodnie z komunikatem. |
