description: "Wszystkie kody, które Opero i opero-ext zgłaszają, gdy paczka rozszerzenia, jej formularze, listy lub strony są odrzucane, testy albo przypadki renderowania bloków nie przechodzą przy przesłaniu, plan instalacji wykrywa problem, krok, zdarzenie, uruchomienie harmonogramu albo akcja bloku lub polecenie rekordu uruchomione przez członka kończy się błędem, połączenie członka się nie udaje, eksport coś pomija albo polecenie administratora zostaje odrzucone, wraz ze sposobem naprawy."
---

Każdy problem ma kod, plik, linię w tym pliku i miejsce w jego wnętrzu, np. `actions/greet/rule.yaml:9 #/steps/0/config/url`. Wszystkie problemy we wszystkich plikach są zgłaszane w jednym przebiegu.

## Gdy paczka jest odrzucana

Wykrywa je `opero-ext validate`, a potem ponownie Opero przy przesłaniu.

### Manifest i pliki

| Kod | Co jest nie tak | Poprawka |
| --- | --- | --- |
| `manifest.missing` | Brak `extension.yaml` na najwyższym poziomie zipa. | Spakuj folder, który go zawiera. |
| `manifest.unsupported_version` | Paczka z `manifest.json` (stary format) albo inna wartość `manifestVersion`. | Przepisz ją w obecnym formacie. |
| `manifest.invalid` | Klucz, którego nie zna `extension.yaml` ani `module.yaml`, albo błędna wartość. | Sprawdź pisownię w [dokumentacji](/docs/pl/extensions/reference/manifest). |
| `manifest.unsupported_section` | Zarezerwowana lista `components`. | Usuń ją. |
| `requires.module_undeclared` | Paczka ma obiekty, zapytania albo zakres `documents:generate`, ale w `requires.modules` brakuje `objects`, `queries` albo `documents`. | Dodaj moduł. |
| `manifest.missing_file` | Deskryptor wskazuje plik, którego nie ma. | Dodaj plik albo popraw nazwę. |
| `file.invalid_yaml` | Plik nie jest poprawnym YAML-em: wcięcia, zabłąkany `:`, pusty plik. | Popraw wskazaną linię; tekst zawierający `: ` weź w cudzysłów. |
| `file.yaml_feature_not_allowed` | Kotwica, alias, tag, klucz scalania albo drugi dokument. | Wpisz wartości wprost. |
| `archive.invalid_path` | Wielkie litery lub spacje w nazwie pliku używanego przez paczkę. | Używaj małych liter, cyfr, `.`, `_`, `-`. |
| `archive.invalid` | Plik nie jest zipem, który da się odczytać. | Spakuj folder narzędziem wiersza poleceń. |
| `archive.too_large` | Zip albo to, co z niego wypakowano, przekracza limit rozmiaru. | Zobacz [Limity](/docs/pl/extensions/reference/limits). |
| `archive.too_many_entries` | Zip zawiera więcej plików, niż pozwala limit. | Usuń pliki, których paczka nie używa. |
| `archive.entry_too_large` | Jeden plik przekracza limit rozmiaru pliku. | Zmniejsz go albo podziel. |
| `archive.unsafe_path` | Ścieżka, która wychodzi poza folder, dowiązanie albo ta sama ścieżka dwa razy. | Spakuj folder narzędziem wiersza poleceń. |
| `manifest.reserved_key` | `extension` zaczyna się od `x-`. | Pomiń ten przedrostek; Opero dodaje go samo. |
| `requires.invalid_release` | `requires.opero` nie jest minimalnym wydaniem, takim jak `">=2026.22.0"`. | Zapisz go w tej postaci. |
